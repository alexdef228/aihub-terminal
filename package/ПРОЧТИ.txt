AIHUB Терминал — окно для Claude Code (и Codex) на Windows
==========================================================

УСТАНОВКА
  1. Распакуй архив целиком (не запускай изнутри zip).
  2. Двойной щелчок по «Установить.cmd».
     Он сам поставит что нужно (Python, Node.js, Claude Code), сделает
     ярлык «AIHUB Терминал» на рабочем столе и запустит окно.
  3. Windows может предупредить «Неизвестный издатель» — программа не
     подписана. Нажми «Подробнее» → «Выполнить в любом случае».

ПЕРВЫЙ ЗАПУСК
  «＋ Новая вкладка» → «📁 Папки с проектами» → «＋ Папка, где лежат проекты».
  Выбери папку, где у тебя проекты: каждая папка внутри станет проектом
  в списке. Папок можно добавить несколько, лишнюю — «Убрать из списка»
  (сами файлы при этом не трогаются).

  Войти в Claude: в окне-чате набери /login (нужна подписка Claude Pro/Max
  или ключ API).

ОБНОВЛЕНИЕ
  Скачай новый архив и снова запусти «Установить.cmd». Твои папки
  и настройки сохранятся.

УДАЛЕНИЕ
  %LOCALAPPDATA%\Programs\AIHUB Terminal\Удалить.cmd
  Проекты и сессии Claude не удаляются.
